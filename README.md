# Stonepit AI Labs

Stonepit AI Labs is a Windows x64 desktop preview for locally managed AI creative workflows. Models and compatible runtimes require separate setup and downloads.

## Release status

The 1.0.0 installer is being prepared as a preview. It is unsigned. Local syntax checking and 54 automated tests passed on 2026-09-25. Clean-PC installation, real GPU generation, phone pairing, and two-PC Team workflows still need verification.

The installer does not include model weights. Individual catalog models depend on compatible hardware and runtime components.

Download only from the Releases page when a preview is published, and verify its SHA-256 checksum.
