# Stonepit AI Labs

Stonepit AI Labs is a Windows x64 desktop preview for locally managed AI creative workflows. Models and compatible runtimes require separate setup and downloads.

## Download

Download the [1.0.0 preview installer and checksum](https://github.com/tanjir49/stonepit-ai-labs/releases/tag/v1.0.0-preview.1) from GitHub. The installer is also available on [Hugging Face](https://huggingface.co/spaces/tanjir49/stonepit-ai-labs). The automatic GitHub source archives contain only this repository README; they are not installers.

The installer is unsigned. Local syntax checking and 54 automated tests passed on 2026-09-25. Clean-PC installation, real GPU generation, phone pairing, and two-PC Team workflows still need verification. Model weights are not included.
