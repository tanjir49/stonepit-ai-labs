# Stonepit AI Labs

Stonepit AI Labs is a Windows x64 desktop preview for locally managed AI creative workflows. Models and compatible runtimes require separate setup and downloads.

## Release status

The `v1.0.0-preview.1` pre-release page is online, but its Windows installer and SHA-256 checksum are not attached yet. The automatic source archives contain only this repository README; they are not installers.

The current installer is unsigned. Local syntax checking and 54 automated tests passed on 2026-09-25. Clean-PC installation, real GPU generation, phone pairing, and two-PC Team workflows still need verification. Model weights are not included.
